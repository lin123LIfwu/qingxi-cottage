# 青溪小筑 · 治愈系 3D 田园小游戏

一个用 **three.js** 制作的轻松休闲田园小游戏：在小河与池塘环绕的山谷里，经营自己的小木屋和菜园，开垦、播种、浇水、收获，去池塘和小河钓鱼，在小树林里闲逛。

## 直接游玩
打开 `dist/青溪小筑.html`（单文件，已内联全部代码，可离线运行）。推荐使用电脑上的新版 Chrome / Edge / Firefox / Safari（需要 WebGL2），键盘 + 鼠标操作。

## 操作
| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动（相对镜头方向） |
| Shift | 奔跑 |
| 空格 | 跳跃（钓鱼收线时按住提竿） |
| 鼠标左键 | 使用当前工具：锄地 / 浇水 / 播种 / 钓鱼（按住蓄力，松开抛竿） |
| E | 互动：收获、出货箱、种子铺、睡觉、看告示牌、装水 |
| 1–9 / Alt + 滚轮 | 切换工具和种子 |
| 拖动鼠标 / Q R | 旋转视角 |
| 滚轮 | 缩放镜头 |
| Tab / L / H / M / Esc | 背包 / 图鉴 / 玩法说明 / 小地图 / 设置 |

## 玩法要点
- 时间：游戏内 1 天约等于现实 16 分钟，可在左上角切换 1× / 2× / 4× 速度；晚上回小屋床边按 E 睡觉进入新的一天（熬到凌晨 2 点会自动晕倒回家）。
- 种田：锄头开垦 → 选种子播种 → 水壶浇水（每天浇一次才会生长，下雨天自动浇水）→ 成熟后按 E 收获。
- 作物：小白菜、胡萝卜、草莓（可重复收获）、番茄（可重复收获）、玉米、南瓜，生长天数和售价各不相同。
- 钓鱼：面向水面按住左键蓄力，松开抛竿；浮漂猛地下沉时立刻点击，随后按住左键/空格让绿条罩住鱼，进度条满即可钓上。池塘、小河、上游溪流各有不同的鱼，不同时段和雨天也会出现特别的鱼（共 12 种，可在图鉴查看）。
- 经济：收获和鱼放进小屋门前的出货箱卖钱，在种子铺购买种子，以及“大号水壶”“精制鱼竿”两项升级。
- 进度会自动保存在浏览器本地（localStorage）。

## 开发
```bash
npm install
npm run build        # 打包为 dist/青溪小筑.html（单文件）
npm run dev          # 本地静态服务器 http://localhost:5173 （index.html 通过 import map 直接加载 src/ 源码）
```
URL 参数：`?quality=low|medium|high` 指定画质，`?autostart=1` 跳过标题。

## 代码结构
```
src/
  main.js              游戏主循环、输入、工具与交互、昼夜/睡眠、存档
  config.js            地图关键位置与常量
  world/terrain.js     程序化地形（平原+山丘）、河流样条与瀑布、池塘、路径、地表纹理
  world/water.js       水面：屏幕空间折射/反射(SSR)、吸收散射、流向贴图流动、细碎波光、岸边泡沫、涟漪
  world/environment.js 物理天空、太阳/月亮、阴影、雾、天气、环境光照
  world/vegetation.js  树木/小树林/灌木/花草/芦苇/荷叶（实例化 + 风动画）
  world/structures.js  小木屋、种子铺、出货箱、码头、木桥、栅栏、路灯等
  game/farm.js         田地、作物生长、浇水
  game/fishing.js      钓鱼流程与水中鱼群
  game/fishData.js     12 种鱼的数据、模型与图标
  game/player.js       卡通角色与动画      game/camera.js  第三人称镜头
  render/pipeline.js   HDR 渲染、MSAA、泛光、ACES 色调映射与调色
  fx/particles.js      雨、水花、泥土、萤火虫、蝴蝶、炊烟、瀑布水雾
  audio/audio.js       WebAudio 程序化音效、环境声与五声音阶背景音乐
  ui/                  HUD、小地图、面板、图标与样式
```
