# 青溪小筑 · 治愈系 3D 田园小游戏

一个用 **three.js** 制作的轻松休闲田园小游戏：在小河与池塘环绕的山谷里，经营自己的两层木屋和菜园，开垦、播种、浇水、收获，去池塘和小河钓鱼，在小树林里闲逛。木屋可以走进去：一楼有壁炉、厨房角、餐桌和阅读角，沿楼梯上二楼是卧室，床就是睡觉的地方。

> 接手开发？先读 [开发交接.md](开发交接.md)：当前进度、游戏规则、必须遵守的约束和待办都在里面。
>
> 想提升画面和性能？见 [画面与性能优化.md](画面与性能优化.md)（规划中，暂不实施，何时做由项目负责人决定）。

## 直接游玩
打开 `dist/青溪小筑.html`（单文件，已内联全部代码和资源，可离线运行）。推荐使用电脑上的新版 Chrome / Edge / Firefox / Safari（需要 WebGL2），键盘 + 鼠标操作。

这个文件约 **5.7 MB**（5,902,953 字节），GitHub 网页接口传不了这么大的文件，所以仓库里存的是它的 base64 文本分段（`dist/青溪小筑.html.b64.part1…8`）。房屋模型保留了约 11.4 万三角面的细节，因此超过了 Notion 免费版 5 MB 的单文件上传线；如果要在 Notion 里预览，请用付费版或把文件放到静态网站 / 本地打开。下载仓库后在 `models/` 文件夹里运行：

```bash
python3 decode.py      # Windows 上用 python decode.py
```

就会还原出可以直接打开的 `dist/青溪小筑.html`，同时还原 Blender 工程（`models/blend/*.blend`）和 GLB 模型（`models/glb/*.glb`），并自动校验 md5。也可以用 `npm install && npm run build` 自己构建出同一个文件。

也能放在 Notion 等网页预览框 / iframe 里直接打开：游戏不依赖 WebAssembly、Worker 或任何外部网络资源，在禁止 `unsafe-eval` / WebAssembly 的严格内容安全策略（CSP）下也能运行；如果所在环境不允许本地存储，照样可以玩，只是不会保存进度。

## 玩法要点
- 时间：游戏内 1 天约等于现实 16 分钟，可在左上角切换 1× / 2× / 4× 速度；晚上回到木屋，走上二楼卧室，在床边按 E 睡觉进入新的一天（熬到凌晨 2 点会自动晕倒回床上）。
- 木屋：一栋两层木屋，石基座、深出檐、烧杉板外墙。进门会自动切到第一人称：一楼有壁炉、炉边椅、厨房角、餐桌和窗边阅读角；沿北墙的直梯上二楼是坡屋顶卧室，床头有天窗，床就是睡觉的交互点。出门恢复原来的视角。屋里有暖灯、壁炉火光和窗外光，雨天雨丝不会穿进屋顶。
- 种田：锄头开垦 → 选种子播种 → 水壶浇水（每天浇一次才会生长，下雨天自动浇水）→ 成熟后按 E 收获。
- 作物：小白菜、胡萝卜、草莓（可重复收获）、番茄（可重复收获）、玉米、南瓜，生长天数和售价各不相同。
- 钓鱼：面向水面按住左键蓄力，松开抛竿；浮漂猛地下沉时立刻点击，随后按住左键/空格让绿条罩住鱼，进度条满即可钓上。池塘、小河、上游溪流各有不同的鱼，不同时段和雨天也会出现特别的鱼（共 12 种，可在图鉴查看）。
- 经济：收获和鱼放进小屋门前的出货箱卖钱，在种子铺购买种子，以及“大号水壶”“精制鱼竿”两项升级。
- 进度会自动保存在浏览器本地（localStorage）。

## 开发
```bash
npm install
npm run build        # 打包为 dist/青溪小筑.html（单文件）
npm run dev          # 本地静态服务器 http://localhost:5173 （index.html 通过 import map 直接加载 src/ 源码）
```
URL 参数：`?quality=low|medium|high` 指定画质，`?autostart=1` 跳过标题。

## 代码结构
```
src/
  main.js              游戏主循环、输入、工具与交互、昼夜/睡眠、存档
  config.js            地图关键位置与常量
  world/terrain.js     程序化地形（平原+山丘）、河流样条与瀑布、池塘、路径、分层高度混合的写实地表材质、四周连绵的远山
  world/grass.js       GPU 写实草地：细长草叶在顶点着色器中成簇生成（世界锚定网格、分块视锥剔除、远近两层渐变、风浪、角色拨开）
  world/water.js       水面：屏幕空间折射/反射(SSR)、吸收散射、流向贴图流动、细碎波光、岸边泡沫、涟漪
  world/environment.js 物理天空、太阳/月亮、阴影、高度雾与空气透视、天气、环境光照
  world/vegetation.js  植被布局：树木/灌木/石头/原木树桩/花草/芦苇/荷叶，烘焙草地密度图
  world/trees.js       写实树木与灌木的实例化渲染：远近两级 LOD、视锥剔除、阴影范围管理、风动画
  gen/treegen.js       程序化写实树木：递归枝干骨架 → 树皮管道网格 + 弯折树叶卡片（橡树/白桦/樱花/苹果/云杉/花灌木），以及原木与树桩
  gen/texgen.js        载入时用 GPU 程序化烘焙写实材质：草皮/泥土/田土/碎石/岩石/林地 + 四种树皮（含法线与 AO）
  gen/leafgen.js       Canvas 程序化绘制树叶、针叶、花朵与果实图集
  util/meadow.js       地面与草叶共用的草场变化（枯黄/茂盛/高矮）
  util/meshoptDecoder.js 纯 JavaScript 的 Meshopt 模型解压（不用 WebAssembly，严格 CSP 环境也能加载）
  world/structures.js  种子铺、出货箱、码头、木桥、栅栏、路灯等（旧木屋已由 house.js 取代）
  world/house.js       两层木屋运行时：楼层碰撞/高度、自动门、室内灯、床交互、镜头遮挡体
  world/colliders.js   2D 碰撞（盒子/圆），支持按楼层过滤
  game/farm.js         田地、作物生长、浇水
  game/fishing.js      钓鱼流程与水中鱼群
  game/fishData.js     12 种鱼的数据、模型与图标
  game/player.js       玩家：移动、跳跃、手持工具，把游戏状态交给人物动画
  game/human.js        人物动画：程序化步态（走/慢跑/快跑）、待机、跳跃、IK 贴地、各种劳作和钓鱼动作
  game/camera.js       镜头：第三人称跟随 + 第一人称（鼠标锁定环顾、视角平滑过渡、准星选地块）
  game/viewmodel.js    第一人称手持工具与手势（锄头/水壶/鱼竿/种子袋），钓到的鱼双手捧起展示
  game/fpArms.js       第一人称手臂：主角模型自己的双臂（按蒙皮权重切出），用人物动画同一套 IK 和手指弯曲驱动
  assets/models.js     载入内嵌的 GLB 模型（Meshopt 压缩 + WebP 贴图），供第一/第三人称共用
  assets/*.glb.js      Blender 制作的工具模型（base64 内嵌，便于打包成单文件）
  assets/farmer*.js    主角人物模型（MakeHuman 人体 + 渔夫帽，带骨骼蒙皮，分段内嵌）
  assets/house*.js     两层木屋 GLB（分段 base64 内嵌）与同源生成的 houseLayout.js（碰撞/楼层/灯位）
  render/pipeline.js   HDR 渲染、MSAA、泛光、ACES 色调映射与调色
  fx/particles.js      雨、水花、泥土、萤火虫、蝴蝶、炊烟、瀑布水雾
  audio/audio.js       WebAudio 程序化音效、环境声与五声音阶背景音乐
  ui/                  HUD、小地图、面板、图标与样式
models/                Blender 模型源文件（工具和人物的 .blend / .glb / 生成脚本），见 models/README.md
dist/                  游戏单文件的 base64 分段（models/decode.py 还原，或 npm run build 重新构建）
```

## 更新记录
- **写实环境（进行中）**：草地改为 GPU 生成的写实草叶，地面改为程序化烘焙的写实分层材质（泥土小路、田土、河岸碎石、岩石、林下落叶）；水面与池塘保持原样。
- **写实树木**：所有树木与灌木改为程序化生成的写实模型——真实分叉的枝干、带法线的树皮贴图、成簇的叶片卡片（橡树、白桦、樱花、苹果树、云杉、白/粉/蓝花灌木），近处高细节、远处自动降级；原木和树桩也换成了带年轮截面与青苔的写实版本。
- **第一人称视角**：按 V、点右上角眼睛按钮，或把滚轮拉到最近即可切换；点击画面锁定鼠标后移动鼠标环顾，Esc 释放。屏幕中央有准星，对准哪块地就耕作 / 浇水 / 播种 / 收获哪块；能看到自己的双手握着锄头、水壶、鱼竿、种子袋，锄地、浇水、撒种、拔菜、抛竿收线都有对应的手部动作，钓到的鱼会双手捧到眼前展示。设置里可以切换视角、调节鼠标灵敏度。
- **写实工具模型**：锄头、水壶、鱼竿、种子袋换成用 Blender 制作的写实模型（PBR 材质：木柄与锻铁锄头、烤漆铁皮水壶配黄铜莲蓬头、竹节竿身配软木握把和金属摇轮、印刷纸质种子袋），第一人称和第三人称手里拿的都是同一套模型；鱼竿的摇轮会随收线转动、竿梢随拉力弯曲，种子袋上的图案会随所选作物变化。模型源文件放在 `models/` 文件夹。
- **写实人物**：主角换成写实比例的青年（身高约 1.75 m）：头戴沙色棉帆布渔夫帽，鼠尾草绿短袖 T 恤、牛仔裤、休闲鞋。人体来自 MakeHuman（CC0），在 Blender 里绑定 53 根骨骼的游戏骨架。动作全部实时程序化合成：走路 → 慢跑 → 快跑（Shift）平滑过渡、脚步贴合地形、待机呼吸和张望、跳跃落地缓冲、扛锄头 / 提水壶 / 握鱼竿 / 拿种子袋走动，锄地、浇水、装水、播种、收获、蓄力抛竿、摇轮收线、举起渔获。第一人称下看到的是同一个人的短袖手臂，地上照样有自己的影子。模型源文件在 `models/`（见 `models/character/README.md`）。
- **兼容性修复**：在 Notion 等内嵌预览里打开时，因为页面的安全策略禁止 WebAssembly，模型解压失败导致“加载时出了点问题”。现在改用纯 JavaScript 解压模型（结果与原来的 WebAssembly 解码器逐字节一致，只多花几十毫秒），贴图直接从内存解码、不再经过 blob: 地址；在禁止本地存储的沙盒 iframe 里也能正常启动（只是不存档）。
- **资源文件进仓库**：游戏单文件（现约 5.7 MB）也以 base64 分段存进了仓库；`models/decode.py` 一次还原全部资源（游戏、6 个 Blender 工程、6 个 GLB），按 `models/checksums.md5` 校验，分段缺失或损坏会提示具体是哪个文件；新增 `models/encode.py` 用来重新生成分段。
- **第一人称真人手臂**：第一人称看到的手不再是几何形状拼的，而是主角模型自己的两条手臂——同一套皮肤贴图、T 恤袖子、指节和指甲，由第三人称同一套两段 IK 和手指弯曲驱动：手指真的扣在锄头柄、水壶提手、鱼竿握把上，伸远时肩膀会跟着前送；收线时左手从下方抬起捏住摇轮把手转动，收获时左手张开、握住、往上拔，钓到的鱼用双手掌心朝上托着，手的间距随鱼的大小变化。
- **草地、光影与远山**：草叶改成细长、成簇生长的草丛（更密，根部有阴影），不再是一根根宽扁的叶片；雾改为贴地的高度雾 + 空气透视，晴天近处清透，远处的山渐渐融进淡蓝的天边，清晨山谷里有薄雾，雨天灰蒙蒙；暗部补光调低、早晚稍微补光，明暗更分明、更有立体感；四周的远山重做成连绵起伏的山脉（山脊、河谷出口，按高度和坡度长森林、露岩石、积雪）。另外修复了睡觉一觉到天亮时画面会闪一帧白。
- **两层木屋**：原来代码拼的小木屋换成一栋在 Blender 5.1.2 里程序化建模的两层木屋——石砌基座、40° 石板瓦坡屋顶、深出檐、一层烧杉板 / 二层风化银灰杉板、外露木梁、西侧毛石烟囱和门廊。玩家可以走进去：一楼有壁炉、炉边椅、厨房角、餐桌、窗边阅读角和上二楼的直梯；二楼坡屋顶下是卧室，床头有天窗，床就是睡觉的交互点。进屋自动切第一人称（镜头经门洞过渡），出门恢复原视角；室内有暖灯、壁炉火光、窗户夜光和窗外光，雨天雨丝不会穿进屋顶，室内还做了近裁剪、楼板分层碰撞和低帧率分步防穿墙。按项目负责人决定保留约 114k 三角面的细节，单文件因此约 5.7 MB，改用 8 段 base64 存放。模型流水线、布局单一数据源和测试见 `models/README.md`、`models/source/house/` 与 `test/`。
- **开发约束放宽**：项目负责人有了本地开发环境，以后的开发不再要求游戏必须是单个离线 html、必须能在 Notion 预览这类严格安全策略（CSP）下运行，可以拆成多个文件、用 WebAssembly 和 Web Worker；仓库改用本地 git 命令行提交，以后大文件可以直接提交，不必再转 base64 分段（现有分段暂时保留）。详见 `开发交接.md` 第 7 节。现有构建方式不变，仍可双击单文件游玩。
